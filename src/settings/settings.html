让讲解适合你的学习方式

配置模型服务，再为每个英文水平定制教学重点。保存后会同步到已打开的视频面板。

语言设置

目标语言用于翻译和讲解；界面语言仅控制按钮、标签和提示。英文原台词保持不变。

模型服务

各服务分别保存配置；切换服务后点击保存才会生效。

服务不支持 JSON 模式时可取消，插件仍会要求模型返回结构化讲解。

分级讲解 Prompt

默认策略

A1–C2 各有一份独立提示词。可修改讲解语言、教学重点、例句风格和希望跳过的知识。字幕内容、JSON 输出结构与水平筛选规则由插件自动补充，不需要在这里编写。

0 字符切换水平会保留未保存的编辑
修改并保存某个水平的 Prompt 后，视频面板会按新提示词自动重新生成该水平的讲解，每批仍为 5 句。其他水平的提示词不会被改变。
